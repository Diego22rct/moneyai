# Historias de Usuario - Core MoneyAI

Este directorio contiene el mapeo funcional del core MVP implementado en la app.

## Convenciones

- Un archivo por HU
- Formato: `HU-XXX-<slug>.md`
- Cada HU incluye:
  - Historia (Como/Quiero/Para)
  - Prioridad
  - Criterios de aceptación (Given/When/Then)
  - Casos borde
  - Dependencias
  - Trazabilidad técnica
  - Definición de listo

## HU incluidas

- HU-001 Registro por texto
- HU-002 Listado persistente
- HU-003 Validación de extracción
- HU-004 Manejo de errores NLU
- HU-005 Privacidad local-first
- HU-006 Estados de UI
- HU-007 Preparación para STT
